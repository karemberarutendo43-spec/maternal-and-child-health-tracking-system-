# MCHTS Admin User Manual

## Dashboard
- Login with **Username + Password**.
- Use the dashboard to monitor totals, alerts, and pending actions.
- District/Super Admin sees all clinics; Clinic Admin sees clinic-scoped totals.

## Users
In **Users** you create and manage staff accounts:
- **Manage Users**: assign clinics, activate/disable accounts, reset passwords, and review role details.
- **Create User**: create new admin/nurse accounts (then share initial credentials securely).

### Common workflow
1. Create User (or locate in Manage Users)
2. Assign clinic and role
3. Reset password if needed and instruct the user to change it on first login

## Queues
In **Queues** you approve and process pending actions:
- **Activation Queue**: approve/activate self-registered mothers and re-enable disabled accounts.
- **Booking Queue**: review pending bookings and resolve any missing/incorrect information.
- **Transfer Requests**: approve or reject transfers; approvals update clinic assignment and notify downstream pages.

## Registry
In **Registry** you manage reference records used by clinics:
- **Birth Confirmation Books**: maintain/track confirmation book allocations and usage.
- **Stock & Commodities**: view/manage commodities and stock thresholds (reorder levels).
- **EPI Backfill**: correct or backfill EPI data when required (use with supervision).

## Defaulters
In **Defaulters** you monitor missed services across your scope:
- **ANC Defaulters**: overdue ANC follow-ups (clinic-scoped or district-wide depending on admin level).
- **Immunization Defaulters**: overdue EPI doses.

## Reports
In **Reports** you generate evidence and supervision outputs:
- **Monthly Reports**: district/clinic summaries for reporting.
- **Clinical Guidelines**: quick reference rules for consistent logging.
- **EPDS Report**: mental health screening reporting where enabled.
- **Clinic Coverage**: coverage/uptake views to compare clinics.
- **ANC Monthly PDF**: exportable ANC summary where used.
- **Audit Logs**: trace actions (who did what, when) for accountability and troubleshooting.

## Settings
In **Settings** you configure the system:
- **Branding Settings** (Super Admin): set portal images/theme elements.
- **Registration Data**: review/export registration-related configuration/data as needed.
